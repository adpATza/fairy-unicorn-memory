WORLD LANDMARKS - 15 ILLUSTRATED MEMORY CARDS
Created 1 November 2026

15 different landmarks, one unique image for each matching pair. The game makes
the duplicate card automatically. All import cards are 1024 x 1024 PNGs, with
warm cream backgrounds and generous safe margins. There are no printed labels
on the individual cards. Labels appear only on the review contact sheet.

IMPORT
Extract ../landmarks-illustrated-15-v1-cards.zip to its own folder, or select
the cards folder beside this file. In the game's Deck library, choose Import
an image folder, select those 15 images, and save the collection.
Suggested name: World Landmarks
Domain: Landmarks | Style: Illustrated | Complexity: Easy
This collection supports up to 15 pairs (30 playing cards).
Import only the cards folder; keep review sheets outside it.

METHOD
Generated with the built-in image_gen tool, one call per landmark. The original
butterfly thread 01a191d5-eb59-7430-9dcc-c615495770ff supplied the style context.
Its first butterfly card was used as an art-style reference for the Eiffel
Tower; that tower illustration was the style reference for the other landmarks.
The full prompt set is included. Images are simplified artistic interpretations.

Each entire original was uniformly resized to 820 x 820 and centered on a
1024 x 1024 canvas. Blank edge colours were extended into the added 102-pixel
margin. No landmark was cropped or stretched. Original files are unchanged.

VERIFICATION
15 import cards, 15 unique decoded images, 15 flat PNG entries in the ZIP.
ZIP entry hashes match the cards; retained originals match generated sources.
All 15 reviewed together at contact-sheet and 100-pixel thumbnail sizes.
Not imported or play-tested in the running game. Easy is the intended difficulty.
