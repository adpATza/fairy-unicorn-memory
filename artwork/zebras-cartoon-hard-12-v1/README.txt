CUTE ZEBRAS - HARD
Created 1 November 2026 with the built-in image_gen tool.
Context: thread 01a191d5-eb59-7430-9dcc-c615495770ff.

12 unique cartoon zebra images, supporting up to 12 matching pairs (24 cards).
Each pair uses two identical copies of one image; the game creates the copies.
The six related pose families are standing, prancing, sitting, resting, bowing and hopping.
Consistent character, palette and background make this a deliberately hard collection.
Head angle, ear position, expression and limb arrangements distinguish similar cards.

IMPORT
Open the game's Deck library > Import an image folder.
Choose this collection's cards folder, which contains exactly 12 PNGs.
Suggested name: Cute Zebras - Hard; domain: Zebras; style: Illustrated; complexity: Hard.
Save the deck, then select up to 12 pairs in setup.
Alternatively, extract the adjacent zebras-cartoon-hard-12-v1-cards.zip and import its folder.
Do not import the collection root or the originals folder.

FILES
cards/: import-ready 1024 x 1024 PNGs; no text, labels or card borders.
originals/: unmodified 1254 x 1254 generated source PNGs.
contact-sheet.png: labelled overview, for review only.
thumbnail-review-100px.png: all twelve images displayed at 100 x 100 pixels.
prompts-and-manifest.json: exact prompts, character reference and pose plan, observed differences.
verification.json and SHA256SUMS.txt: dimensions, uniqueness, file and ZIP validation.
package.ps1: repeatable local packaging script (uses the recorded generation source paths).

NORMALIZATION
Each complete source image is proportionally resized to 896 x 896 and centered in a
1024 x 1024 square. Only the blank edge background is extended into the extra margin.
No subject cropping, stretching, repainting or palette changes are performed in packaging.

VALIDATION BOUNDARY
Generated cards were visually reviewed individually and together at 100 pixels.
One extra leg on card 09 was corrected using image_gen before delivery.
12 distinct decoded images and 12 matching flat ZIP entries are checked by package.ps1.
The collection has not been imported or play-tested in the running game.
Difficulty is a design intention and has not been measured through play.
